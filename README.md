# Saurabh Meena - Personal Portfolio

A minimal, modern, and highly interactive personal portfolio website built with modern web technologies. This repository contains the source code for my personal website, showcasing my projects, skills, education, and social links.

## 🚀 Live Demo

[saurabhmeena.dev](https://saurabhmeena.dev)

## ✨ Features

- **Modern Tech Stack**: Built with Next.js 16 (App Router) and React 19.
- **Beautiful Styling**: Styled with Tailwind CSS v4 for a utility-first approach.
- **Smooth Animations**: Uses Framer Motion and Magic UI for delightful, fluid animations (like the floating dock and blur fade effects).
- **Fully Responsive**: Carefully designed to look great on both desktop and mobile devices.
- **Dark/Light Mode**: Seamless theme switching with `next-themes`.
- **Easy Configuration**: All personal data, projects, and social links are managed centrally in `src/data/siteConfig.ts` for incredibly easy updating and cloning.

## 💻 Running Locally

If you'd like to run this project locally or use it as a template:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/saurabhxmeena/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application running.

## 📝 Customization

To use this portfolio for yourself, simply modify the `src/data/siteConfig.ts` file! You can easily update:
- Your name, bio, and avatar
- Education and experience
- Portfolio projects (including links, dates, and descriptions)
- Social media links and navbar items
