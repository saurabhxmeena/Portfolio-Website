# srbhxme.site

hey! this is the source code for my personal portfolio website. 
i built it to showcase my projects, what i'm learning, and a bit about me.

you can check it out live here: [srbhxme.site](https://srbhxme.site)

### how it's built
- **Next.js** for the framework
- **Tailwind CSS** for styling
- **Framer Motion & Magic UI** for the smooth animations

### run it yourself
if you want to run it locally or use it as inspiration:
1. clone this repo
2. run `npm install`
3. run `npm run dev`
4. open `http://localhost:3000`

feel free to reach out if you have any questions or just want to say hi!
